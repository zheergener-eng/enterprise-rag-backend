# 服务器部署与日常运维规范

## 1. 文档说明与适用范围

本文档定义服务器的部署、巡检、监控、重启与变更要求，适用于服务器管理员及相关值班工程师。

## 2. 术语

| 术语 | 说明 |
| --- | --- |
| 生产服务器 | 部署在 A3 机房、承载真实业务流量的服务器 |
| 测试服务器 | 部署在 B1 机房、用于发布前验证的服务器 |
| 变更窗口 | 允许执行高风险变更的时间段 |
| 事件单 | 用于登记硬件故障与异常的工作项 |
| 巡检 | 按固定频率对服务器健康状态进行的例行检查 |

## 3. 机房部署

| 环境 | 机房 |
| --- | --- |
| 星河项目生产服务器 | A3 机房 |
| 测试服务器 | B1 机房 |

生产服务器与测试服务器分处不同机房，网络与权限相互隔离。生产服务器操作需审批，测试服务器操作相对宽松，但同样要求登记操作记录。

## 4. 每日巡检

服务器管理员每日执行巡检，内容包括：

- CPU、内存、磁盘使用率是否在阈值内；
- 风扇、散热是否正常；
- 是否有硬件告警或异常日志。

巡检发现异常应及时登记并跟进。

## 5. 每周深度巡检

除每日巡检外，服务器管理员每周执行一次深度巡检，内容包括：

- 磁盘 SMART 状态与健康度；
- 硬件日志与系统日志；
- 补丁与安全更新状态；
- 网络流量与连接数异常。

深度巡检结果需记录归档，发现隐患应提前处置。

## 6. CPU 温度过高处理

当服务器 CPU 温度过高触发告警时，按顺序检查：

1. 风扇是否正常运转；
2. 散热模块是否积灰或失效；
3. 环境温度是否异常升高。

若上述检查均正常但温度仍持续过高，应登记事件单并评估是否降载或迁移服务。

## 7. 资源阈值

| 指标 | 告警阈值 | 处理要求 |
| --- | --- | --- |
| CPU 使用率 | 连续 5 分钟 > 85% | 定位高负载进程 |
| 内存使用率 | > 90% | 告警；持续 > 95% 评估重启服务 |
| 磁盘剩余空间 | < 20% | 告警；< 10% 立即清理或扩容 |

磁盘剩余空间低于 10% 时，需立即清理日志或扩容，避免写满导致服务异常。

## 8. 磁盘与日志管理

服务器日志应按策略轮转，避免日志无限增长占满磁盘。磁盘空间不足时，优先清理可安全删除的旧日志，再评估扩容。日志清理不得影响故障排查所需的历史日志。

## 9. 容量与扩容流程

服务器磁盘或内存不足时，按以下流程处理：

1. 评估当前使用量与增长趋势；
2. 优先清理可回收空间；
3. 需扩容时，在变更窗口内执行并验证；
4. 记录扩容结果。

## 10. 服务器重启流程

服务器重启属于高风险操作，必须遵循以下流程：

1. 提前申请并安排在变更窗口内；
2. 重启前确认数据已落盘、依赖已处理；
3. 重启后验证服务与监控是否恢复正常。

未经审批，禁止在业务高峰期间重启生产服务器。

## 11. 变更窗口

生产环境变更窗口为每周二、四 22:00 至次日 02:00。服务器重启、配置变更等操作应尽量安排在变更窗口内执行。紧急变更不受窗口限制，但事后必须补登记。

## 12. 系统补丁与升级

服务器操作系统与应用补丁应定期评估并升级。补丁升级前需在测试环境验证，确认无异常后再安排生产升级。生产升级应安排在变更窗口内。

## 13. 权限差异

生产环境与测试环境的操作权限不同：生产服务器仅授权运维角色操作，测试服务器可由开发与测试人员操作，但均要求登记操作记录。账号权限的申请、变更与回收遵循《权限控制与安全审计规范》。

## 14. 硬件故障登记

服务器硬件故障（风扇、散热、磁盘等）必须登记事件单，记录故障现象、影响范围与处理结果。硬件故障处理完成后需复盘，评估是否需更换硬件或调整部署。

## 15. 告警响应与处理

服务器告警触发后，服务器管理员应：

1. 确认告警内容与影响范围；
2. 按对应阈值章节的处理要求执行；
3. 处理完成后记录结果并关闭告警。

严重告警需立即响应，必要时升级处理。
